Python Tip Calculator

Project Overview

This is a beginner Python practice project that calculates a restaurant tip, the total bill including the tip, and how much each person should pay when splitting the bill.

I created this project to practice basic Python programming and learn how to upload and share code using GitHub.

Features

Enter the original restaurant bill amount.

Choose a tip percentage.

Calculate the tip amount.

Calculate the total bill including the tip.

Split the total equally among multiple people.

Example

For a $50 bill with a 20% tip split between 3 people:

Original bill: $50.00

Tip percentage: 20%

Tip amount: $10.00

Total bill: $60.00

Number of people: 3

Amount per person: $20.00

How to Run the Program

Open the TipCalculator.ipynb file in Jupyter Notebook.

Run the code cells in order.

Enter the original bill amount when prompted.

Enter the percentage you would like to tip.

Enter the number of people splitting the bill.

Review the calculated tip, total bill, and amount each person owes.
